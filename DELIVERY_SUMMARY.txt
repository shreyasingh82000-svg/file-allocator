                         🎯 KEY FEATURES
================================================================================

FILE ALLOCATION ALGORITHMS:

  🔵 CONTIGUOUS ALLOCATION
     • All blocks stored consecutively
     • Fast direct access
     • Suffers from external fragmentation
     • Algorithm: Linear search for consecutive blocks

  🟣 LINKED ALLOCATION
     • Blocks scattered with pointer chains
     • No external fragmentation
     • Slower access through pointers
     • Algorithm: Select free blocks and create chain

  🟠 INDEXED ALLOCATION
     • Index block stores all data block addresses
     • No external fragmentation
     • Fast random access
     • Algorithm: Allocate index + data blocks separately
