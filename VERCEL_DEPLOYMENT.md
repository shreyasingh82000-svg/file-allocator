# Deploy to Vercel Now! 🚀

Your project is ready. Here's how to deploy to Vercel in 2 minutes:

## Step 1: Create GitHub Repository

```bash
cd "C:\Users\Shreya Singh\Desktop\OS\file-allocator"

# If you haven't already, create a new repository on GitHub first
# Then run:

git remote add origin https://github.com/YOUR_USERNAME/file-allocator.git
git branch -M main
git push -u origin main
```

## Step 2: Deploy on Vercel

1. **Go to**: https://vercel.com/new
2. **Click**: "Import Git Repository"
3. **Paste**: `https://github.com/YOUR_USERNAME/file-allocator`
4. **Click**: Import
5. **Framework**: Select "Vite" (or leave as Other)
6. **Root Directory**: Leave as `.`
7. **Build Command**: `npm run build`
8. **Output Directory**: `dist`
9. **Click**: Deploy

## That's it! ✅

Your site will be live at: `https://file-allocator.vercel.app`

---

### Alternative: Drag & Drop on Vercel

If you don't want to use GitHub:

1. Go to: https://vercel.com/new
2. Choose "Other"
3. Upload the `dist/` folder directly
4. Done! 🎉
